Neon Verbale

Meeting transcripts with the name of whoever is speaking, entirely on your own PC. Formerly Trascrittore riunioni (up to version 1.1.0).

The program's window speaks English, Italian, Spanish, French, Portuguese and Chinese: choose with the Interface menu at the top right. This guide uses the English labels. The installers and the names of the result files are in Italian.

1. What it does

It takes the recording of a meeting (for example the .mp4 from Microsoft Teams, or a screen recording) and produces:

  • the transcript, split by speaker turn, in Italian, English, Spanish, French, Portuguese or Chinese, or in the language Whisper detects;
  • speaker separation: who said what;
  • the participants' names, when the Teams video shows them;
  • subtitles to use with the video.

It works without accounts or cloud services: everything is processed on your computer.

3. Installation

Windows

  1. Run NeonVerbale-Setup-<version>.exe.
  2. If "Windows protected your PC" appears: the program is not digitally signed. Choose More info and then Run anyway.
  3. Follow the wizard pages: licence, requirements, folder (the proposed one is fine), options. Keep Scarica subito il modello Whisper (download the Whisper model now) ticked, so the first transcription starts right away.
  4. Before installing, the hardware check and required space page tells you which graphics card it found, which build it will install, how much it will download, how much space it needs and how long it will take with your connection. The same figures are summarised on the Pronto per l'installazione (ready to install) page.
  5. During installation the Installazione dei componenti page (installing components) shows the current step, how much has been downloaded, the speed and the time left. With a GPU it takes about 15-30 minutes depending on the connection (13 minutes measured on a fast line); with the CPU build about 10-15 minutes. You can keep using the PC meanwhile.
  6. At the end you can start the program right away.
Upgrading from Trascrittore riunioni (1.1.0 or earlier): just run the new setup. It installs over the existing version, in the same folder, replaces the shortcuts with the new ones and, at the first start, moves voices, glossary and downloaded models under the new name.

The installer creates the desktop shortcut (the quill) and a Neon Verbale folder in the Start menu, with the program, this guide, Ripara componenti (repair components) and Disinstalla (uninstall).

If installing the components fails (usually because of the connection or a corporate proxy), the wizard offers to try again. You can also retry later from Start → Neon Verbale → Ripara componenti.

Linux

You need an x86_64 PC with a recent distribution (glibc 2.28 or later: Ubuntu 20.04+, Debian 10+, Fedora 29+ and similar). No sudo and no system packages are needed.

  1. Download NeonVerbale-<version>-linux-x86_64.run from the Releases page.
  2. Run it with sh NeonVerbale-<version>-linux-x86_64.run, or make it executable (right click → Properties → Allow executing) and double-click it.
  3. The wizard opens: licence, then the hardware check and required space (GPU or CPU build, GB to download, space, time), then the progress with the time left. Without a graphical desktop, or with the --cli option, the same steps run in the terminal.

The program goes in ~/.local/lib/neon-verbale and its data in ~/.local/share/neon-verbale. You find Neon Verbale in the applications menu; in a terminal there is the command ~/.local/bin/neon-verbale:

CommandWhat it does
neon-verbale [video…]opens the window, with the given videos already in the list
neon-verbale --trascrivi video.mp4transcribes from the terminal (see Command line)
neon-verbale --riparareinstalls PyTorch and the libraries, for example after updating the NVIDIA driver
neon-verbale --disinstallaremoves the program, asking whether to keep models and voice library (also from the menu: right click on the icon → Disinstalla)

Installer options: --cli (terminal only), -y (no questions), --cpu (CPU build even with an NVIDIA GPU), --no-models (download Whisper at first use), --no-desktop (no desktop shortcut).

4. How to use it

  1. Open Neon Verbale from the desktop or the Start/applications menu.
  2. Choose the Meeting language: Italian, English, Spanish, French, Portuguese, Chinese, or Detect automatically when you do not know it or it changes from meeting to meeting.
  3. Click Add videos… and pick one or more recordings (you can select several at once with Ctrl or Shift).
  4. Click Start all, or ▶ on the row of a single video.

The queue. You can add more videos at any time, even while one is being processed: the list has no limit and scrolls. Videos are processed one at a time (there is only one graphics card):

  • Start all queues every waiting video. While the queue is running, videos added later join it by themselves.
  • ▶ on a row starts that video right away or, if another one is running, puts it first in the queue.
  • ✕ removes a video from the list (except the one being processed). The same video cannot be in the list twice.
  • On Linux the two row buttons read Start and Remove.

Each video has a bar with the current step and the estimated time left (ETA), or its position in the queue; with several videos there is also the Total row, with the ETA of everything still to do, updated at every addition or removal. Above the list you can see whether the program is using the GPU or the CPU. Open results folder shows the files of the last completed video.

Languages. The Meeting language menu applies to the videos you add afterwards; each row shows its video's language (IT, EN, ES, FR, PT, ZH or AUTO) in a small menu you can change until that video starts, so one queue can mix meetings in different languages. With AUTO, Whisper listens to the first seconds and the log shows the language it found. If you process a video again with a different language, the transcription is redone. The Interface menu changes the window's language at once. Both choices are remembered; the first time the program uses the system's language. Chinese is offered on Windows only: on Linux the window cannot draw Chinese characters (Chinese meetings can still be transcribed).

The window follows the system's light or dark theme, read at start-up.

Shortcut: drop one or more videos on the quill icon on the desktop: the window opens with those files already in the list.

Accepted formats: mp4, mkv, mov, avi, webm and audio-only files (m4a, mp3, wav, ogg). With audio-only files the voices are separated, but names cannot be read.

5. The results

A Trascrizioni folder is created next to the videos, with one subfolder per video:

Meeting-20261020.mp4
Trascrizioni\
  Meeting-20261020\
    trascrizione.md     text to read: participants, speaking time, turns
    trascrizione.srt    subtitles (VLC, video players, editing software)
    trascrizione.vtt    web subtitles, with the speaker's name
    trascrizione.json   all the data, word by word with timestamps
    speakers.json       who is who: can be corrected by hand
    _lavoro\            intermediate results, used to regenerate quickly

trascrizione.md is a plain text file (Markdown): it opens with Notepad, Word or any editor. Turns look like this:

**[00:04:52] Mario Rossi:** A questo proposito, riesci a mandarmi le specifiche entro venerdì?

6. How names are found

  1. The pyannote model listens to the audio and groups the voices (SPEAKER_00, SPEAKER_01...).
  2. In Teams recordings the name of whoever is talking is highlighted with a purple box. The program looks at the video twice a second and reads those names.
  3. For each voice it checks which name is highlighted while that voice is speaking and not while the others are. This way an open microphone, or the label of whoever shares the screen, does not "steal" other people's sentences.
  4. If the video is not enough, it uses the voice library: the voiceprints of people recognised in previous meetings. The library grows by itself with every meeting.
  5. When it is not sure, it writes Speaker 2, sometimes with a hint: Speaker 2 (forse: Mario Rossi) (forse means maybe).
Names are read well from recordings made by Teams. In screen captures of the live Teams client the speaker is signalled differently: there the voice library and manual corrections do the job.

7. Fixing a name

  1. Open speakers.json in the meeting's folder (right click → Open with → Notepad).
  2. Change the "name" value of the wrong voice. For example: 
    "SPEAKER_02": {
  "name": "Giulia Bianchi",
  ...
  3. Save and process the same video again with the program. Only the trascrizione.* files are regenerated, in a second.

The correction also goes into the voice library and helps recognise that person in later meetings. If two different voices are the same person, give both the same name: their turns are merged.

8. Glossary

The Glossary… button opens a text file where you write, one per line, the terms Whisper should spell correctly: project names, acronyms, products, jargon. Example:

ProgettoAlfa
GitLab
fine-tuning

Participant names read from the video are added automatically. The glossary applies to transcriptions made after you change it.

11. Privacy

Audio, video, transcripts and voiceprints stay on your PC. The program connects to the Internet only to download its components (during installation, or at first use if you skipped the model download). The voice library contains voiceprints, which are personal data: do not share it without the consent of the people concerned.

12. Troubleshooting

Installing the components fails

Check the connection and retry from Start → Neon Verbale → Ripara componenti (on Linux: neon-verbale --ripara). The error details are in install.log, in the program folder. Behind an authenticated corporate proxy, ask IT to allow pypi.org, files.pythonhosted.org, download.pytorch.org and huggingface.co.

I have an NVIDIA GPU but the program uses the CPU

The card must be Turing or newer, with at least 4 GB of memory and driver 570 or later. Update the driver from nvidia.com/drivers, then run Ripara componenti: it installs the GPU build if the card is now suitable.

No names, only "Speaker 1", "Speaker 2"

The video is not a Teams recording, or nobody was highlighted while speaking. Fix the names in speakers.json (section 7): from the next time, the voice library will recognise them.

One person was split into two voices, or two people were merged

In the first case give both voices the same name in speakers.json. In the second, with the command line you can give the number of participants with --num-speakers.

Some technical words are spelt wrong

Add them to the glossary and process the video again from the command line with --redo asr.

The program does not open

Look at gui.log in the data folder (section 10) and run Ripara componenti.

13. Command line (for power users)

On Windows, from a PowerShell terminal in the program folder:

cd "$env:LOCALAPPDATA\Programs\Neon Verbale"
.\runtime\python.exe -m meeting_transcriber "C:\path\meeting.mp4"
.\runtime\python.exe -m meeting_transcriber --help

On Linux: neon-verbale --trascrivi meeting.mp4 (and neon-verbale --trascrivi --help).

OptionWhat it does
--num-speakers Nexact number of participants (also --min-speakers, --max-speakers)
--redo asrredoes the transcription (for example after changing the glossary); also video, diarization, names, all
--model large-v3-turboa Whisper model other than the one chosen automatically
--cpudo not use the GPU
--out FOLDERsave the results somewhere else
--language enmeeting language (default it); auto lets Whisper detect it

14. Uninstalling

On Windows: Settings → Apps → Installed apps → Neon Verbale → Uninstall, or Start → Neon Verbale → Disinstalla. You are asked whether to delete the downloaded models and the voice library too; the transcripts next to the videos stay where they are.

On Linux: neon-verbale --disinstalla, or right click on the icon in the applications menu → Disinstalla Neon Verbale. Here too you are asked whether to delete models and voice library.
